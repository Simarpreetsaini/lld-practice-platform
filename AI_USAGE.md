# AI Usage

## 1. Technology selection

AI suggested a FastAPI and SQLite monolith to keep the assignment focused on LLD rather than infrastructure. This was accepted because the assignment allows a monolith.

## 2. Evaluation strategy

AI suggested deterministic checks before adding an LLM. This was accepted because deterministic feedback is easier to explain, test, and run without API costs.

## 3. Domain separation

AI suggested separating the evaluator from the repository. This was accepted because evaluation rules should not depend directly on database code.

## 4. Feedback format

AI suggested category-based feedback with a title, explanation, and severity. This was accepted because learners need actionable explanations instead of only a numerical score.

## 5. Scope control

AI suggested text submissions instead of building a diagram editor. This was accepted because it keeps the MVP achievable within two days.
